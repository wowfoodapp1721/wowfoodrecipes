alt_route TRIGGER & EVENT LIFECYCLE

Tapping row item "Edit recipe" fires route Navigator.pushNamed('/recipe/edit', recipe_id) with slide-up 300ms transition. Tapping "Print recipe" mounts the modal bottom sheet controller with 60% alpha scrim.

undo BACKSTACK & DISMISSAL RULES

Clicking top-left close ('X') icon on Screen 3I or tapping the dimmed scrim on Screen 3J invokes Navigator.pop(), smoothly dropping back to the preserved Screen 3E baseline without state reconstruction.

sync_saved_locally DATA BINDING & SYNC CONTRACT

Screen 3I saves propagate updates to state store (dispatch(updateRecipe(id, payload))) which synchronously re-renders ingredient amounts and nutritional metrics across Screen 3A, 3B, and 3C.
